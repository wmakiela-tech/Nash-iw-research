# NASH–IW Research Infrastructure

Private, versioned code, validators, schemas, manifests and reproducibility support for NASH/IW.

## Storage roles

- **GitHub:** code, tests, schemas, manifests, issues, pull requests and CI.
- **Google Drive:** curated shared state, reading order and cross-cell review packets.
- **File Library:** exact frozen reports, payloads, CSV files and historical artifacts.

## Claim boundary

Green CI means only that declared automated checks passed. It does not confer `EXEC_SIGN`, canon merge, scientific truth or claim upgrade.

## Change path

```text
branch → draft pull request → review → explicit disposition → merge
```

The bootstrap contains no NCDG runtime and no `adjusted_transport` implementation.
