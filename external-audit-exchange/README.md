This directory is a public reviewer handoff for ONLY explicitly approved public-safe scientific material. Public GitHub retains commit history: removing a case from the current branch does NOT erase previous commits, forks, clones, indexing or copies. Never place confidential, restricted, blind/protected, personal, licensed unpublished, or secret content here. If revocable access is genuinely required, do not use public GitHub; use an approved access-controlled temporary file transfer.

## Operational cycle
1. Audit controller AUD1 opens one scoped case ID, assigns source owner, exact claim, falsifier, reviewer, deadline when authorized, permitted exposure, and original immutable source commit/hash.
2. Before public posting, perform source-owner and Moderator exposure check. A public original may be linked instead of duplicated. Freeze reviewer inputs and disclose relevant prior art, source type, excluded targets and independent first-pass protocol.
3. Public reviewer packet is placed under inbox/. Only Moderator or another authorized operator actually forwards it to Grok. PUBLICATION != DELIVERY != RECEIPT.
4. Store FULL reviewer response with exact external provenance, prompt, received time, attachments and checksum on canonical private Nash-Priv (or legal original owner source); preserve reviewer original. Original scientific claim and any correction stay in the original scientific repository.
5. Original scientific owner assesses each objection. AUD1 records item-by-item accepted, rejected with reason, retest, or HOLD. REC10/SW provide their independent scientific scrutiny; only Moderator can authorize final EXEC.
6. After full review response has been durably stored and linked, AUD1 removes the packet from inbox/ on the CURRENT branch and records the deletion commit privately. This is cleanup of the working queue, NOT secure erasure from public Git history. Do not delete scientific original or referee evidence.
7. Reopen only when a concrete material contradiction or missing evidence appears. No audit cascade.

## Independent review contracts
Exposure X0 blind-neutral / X1 frozen common input / X2 contrast exposed / X3 full context collaborative.
Independence I0 not independent / I1 output separated / I2 method diverse / I3 provenance independent. X does not imply I. Blind-first results must be frozen before any contrast exposure. Public discoverability can invalidate a claimed blind condition.

Routine Claude/Badacz reviews retain their independent scope and consent; no automatic subordinate status. REC10 is the formal independent referee, SW science coordinator, KN/BW the scientific evidence registry, and Moderator the sole EXEC authority.
Grok: adversarial external review of public-safe frozen claims. DS or AInstein: project-critical targeted audit using a standalone, permitted file, default Moderator-mediated. No external model receives a task merely because a file appears here.
