# NASH/IW — thin blind-thread launcher for external model families

Use this file **instead of** the common bootstrap digests when a genuinely blind/low-exposure pass is desired.

Do not expose before blind freeze:

- current project answer;
- current scientific answer/state;
- expected conclusion;
- other participants' returns;
- parent priority map;
- current BW neighborhood;
- hidden evaluator criteria.

```yaml
BLIND_G0:
  target_cell_family: AINSTEIN | GROK | DS
  mode: BLIND_BOUNDED
  role: <specific bounded role>
  research_question: <self-contained question>
  legal_sources_exposed: []
  output_required:
    - exposure ledger
    - independent result/reasoning summary
    - uncertainties
    - counterexample/discriminator/test proposal
  after_freeze:
    - comparison to current project state may occur
```

Blindness is an exposure condition, not a prestige label. If the model already retains material project context, disclose it and downgrade the blindness claim.
