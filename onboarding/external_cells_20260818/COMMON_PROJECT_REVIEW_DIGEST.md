## 1. What NASH/IW is

NASH/IW should not be framed as an agentic pipeline. Operationally it is a federated, asynchronous, heterogeneous multi-model scientific collaboration configuration/ecology involving humans, model families, tools, sources, code, storage and research memory.

The project protects three coexisting aims:

- reliable/reproducible science and mathematics;
- study of human–AI and AI–AI collaboration;
- continuity, autonomy, provenance and shared knowledge.

Architecture must not optimize one by starving the others.

## 2. Authority and evidence

The Human Moderator is final authority for consequential project decisions, but is not intended to be routine research router or manual memory.

Load-bearing distinctions:

- `AUTHORITY_STATE != EVIDENCE_STATE`
- `PROJECT_ADOPTED != SCIENTIFICALLY_SUPPORTED`
- `PROJECT_CLOSED != SCIENTIFICALLY_RESOLVED`
- `MODEL_AGREEMENT != EVIDENCE`
- `STORAGE != NOTICE != DELIVERY != RECEIPT != ACCEPTANCE != SCIENTIFIC_VALIDATION`
- `THREAD != CELL`
- `ROLE_CONTINUITY != EXECUTOR_CONTINUITY`

## 4. Why memory architecture changed

Project history showed a `NON_CUMULATIVE_KNOWLEDGE_ARCHITECTURE` failure: many documents existed, yet results, corrections, negative knowledge and prior-art closures were repeatedly reconstructed from scratch. Similar names hid non-identical objects, `FINAL` labels became stale, and local failure modes did not reliably become shared memory.

This led to separation of:

- project operational state;
- scientific knowledge state;
- source/evidence provenance;
- local/model-family working memory;
- public/export surfaces.

A document or folder is a custody/navigation surface, not automatically the scientific knowledge object.

## 5. Current BW/SKS direction

The live knowledge system uses two semantic planes over a shared evidence/provenance spine:

`P-PLANE = Project Knowledge / Project State`

`S-PLANE = Scientific Knowledge`

with explicit typed P↔S bridges and append-only state changes.

Key non-equivalences:

- project currentness is not scientific support;
- project authorization is not evidence;
- scientific support does not automatically enact project policy;
- hash identity is not methodological validity;
- source presence does not itself imply SUPPORTS.

Current state is derived from events rather than destructive rewriting. Conflict and supersession are preserved.

## 6. Collaboration and independence

Different model names are not automatically independent evidence. Independence depends on source exposure, prompt framing, shared code/oracles, project history, analysis path and implementation path.

Blind work is therefore an explicit exposure condition. If a cell receives current project/scientific digests, its reconstruction is **not blind**.

Direct participant-to-participant work is preferred where the environment permits it, but cross-provider direct transport is not assumed. Moderator relay may remain necessary for some providers.
