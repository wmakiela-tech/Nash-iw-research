## 11. Artifact 009 — sacrificial measurement / protocol ceiling

VERDICT: PASS_OPEN-LOOP_CEILING_WITH_QUANTIFIER_REPAIR / PASS_FIXED-TIME_PRECONDITIONING_EFFECT / RETYPE_SACRIFICIAL-MEASUREMENT_CLAIM.

For the pulse instrument:
sigma(s)=(1-exp(-gamma s))/gamma,
y+ = exp(-gamma s) y-.

For a finite predeclared open-loop protocol with separate bounded adversarial error per readout:
M_Pi=max_j |G_j| sigma(s_j).

Energy is nonincreasing, so |G_j|<=1, and for finite strength sigma(s_j)<1/gamma. Therefore M_Pi<1/gamma. This ceiling is sound in that scope.

Repairs:

1. If normalized risk is rho=min(1,delta/(R M_Pi)), the protocol-independent lower bound is:
rho >= min(1,gamma delta/R),
not uncapped gamma delta/R in every regime.

2. For finite s, a one-measurement protocol does not attain the ceiling. A one-measurement family approaches the supremum as s -> infinity, assuming a legal time with |G|=1 or arbitrarily close. Extra measurements do not improve that supremum.

3. "Any protocol" is too broad if it includes adaptive choices based on noisy previous outcomes. Current proof is safe for predeclared/open-loop finite protocols.

4. 009 is a new pulse-limit simultaneous readout/damping model, not literally the same dynamical model as 008.

5. The reported "sacrificial measurement" effect is more precisely preconditioning-assisted observation. For fixed t1=1.40, t2=1.75, Delta=0.35 and first-pulse survivor r=exp(-gamma s1):
G2(r) = -sin(t1) sin(Delta) + r cos(t1) cos(Delta).

As r -> 0:
|G2| -> sin(1.40) sin(0.35) about 0.337909.
Without the first pulse:
|G2|=|cos(1.75)| about 0.178246.
Exact fixed-time gain about 1.89574.

So the mechanism is real and can be derived analytically, not merely seen on a grid.

But the first readout can be discarded without changing the state-preconditioning effect:
READOUT-IRRELEVANT PRECONDITIONING != INFORMATION GAIN FROM FIRST MEASUREMENT.

"Sacrificial measurement" is legal only if the physical instrument class makes readout and damping inseparable. Otherwise use PRECONDITIONING-ASSISTED OBSERVATION.
