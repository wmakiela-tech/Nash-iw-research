2. Mature mathematical host for hidden EP
The hidden-EP case is mathematically controlled by standard stationary stochastic thermodynamics plus partial identification.
For a visible process Y and an independent hidden stationary finite CTMC Z:
sigma_total=sigma_Y+sigma_Z.
If Z is unrestricted, the detector law on Y does not constrain sigma_Z and total EP has an unbounded hidden direction.
If legal hidden-carrier constraints provide
total hidden traffic <= A
and
max hidden edge affinity <= L,
then the mature host gives the sharp bound
0<=sigma_Z<=A L tanh(L/2),
so
sigma_total in [sigma_Y, sigma_Y+A L tanh(L/2)]
whenever sigma_Y is point-identified.
Thus the MATHEMATICAL identified-set logic is already fully absorbed by mature hosts once the admissible hidden-carrier constraint set is fixed.
3. Source-contract layer
The scientific verdict additionally depends on WHY a hidden-carrier constraint is admissible.
Consider the same mathematical carrier constraint C(A,L):
C={hidden stationary finite CTMCs with total traffic<=A and max edge affinity<=L}.
Construct two source contracts with identical equations and identical feasible set C.
CONTRACT P — PHYSICALLY ADMITTED:
A and L are supplied by an independent calibrated measurement, hardware design limit, reservoir specification, or another declared source-native physical constraint.
CONTRACT Q — ANALYST CONVENIENCE:
the identical numerical bounds A and L are inserted only to regularize the model or make the inferred interval finite, with no source-native evidence or declared physical justification.
Mathematically, P and Q induce the SAME parameter set C and therefore the SAME identified interval.
Scientifically, they do not support the same claim ceiling.
4. Exact provenance non-map
Let M denote all mathematical information visible to the mature host: model equations, target definition, feasible set C, detector law, and resulting identified set.
Suppose there existed a universal map
Phi(M)=SOURCE_NATIVE_ADMISSION_VERDICT.
Contracts P and Q above have identical M. Therefore Phi must assign the same verdict to both.
But source-native scientific admission distinguishes them by construction: P has an admitted evidential basis for C; Q does not.
Contradiction.
Hence there is no function from mathematical feasible-set/identified-set structure alone to source-native admission status.
Exact firewall:
SAME MATHEMATICAL CONSTRAINT SET
!=
SAME EVIDENCE PROVENANCE
!=
SAME SCIENTIFIC ADMISSION.
