# PRF12 R22 — Uniform finite-drive source discrimination via physically modeled three-axis analysis pulses

**Data:** 29 October 2026. **Function:** PRF12. **New result:** In a fixed fully specified source-ON square-pulse model with bounded amplitude, three-terminal-axis parity yields a **strictly positive contrast for EVERY fixed real hidden frequency**. This improves the R21 source-ON result, which proved an *exact phase-independent parity law* only if terminal X/Y/Z projective instruments were assumed for free. Here the rotation pulses for X/Y analysis are explicitly propagated with the source ON. **Terminal Z projection and sensor resetting remain ideal instantaneous operations**, so this is NOT a full finite-hardware SPAM proof. The gain is a provable finite-source-ON drive READOUT robustness in a narrow model, not cost efficiency nor an asymptotic LOCC theorem for the original three-probe state.
