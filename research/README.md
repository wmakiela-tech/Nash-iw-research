# Research

Canonical forward location for full **public-safe** scientific bodies.

## New writes

```text
research/<lineage>/<YYYY-MM-DD>/<artifact>.md
```

Use lower-case lineage directory names prospectively. Historical paths such as `research/LT4/`, direct files under `research/mt13/`, and other earlier layouts remain valid immutable provenance and are not mass-renamed.

Every material public research body should expose or make recoverable:
- stable artifact/contribution ID;
- BW ingestion event when known;
- BW qualification/lifecycle ceiling;
- archive mode;
- sync state;
- provenance / derived-from / supersession.

A GitHub file without BW status is archive/evidence only until normal BW ingestion/qualification.

See:
- `../docs/REPOSITORY_STRUCTURE.md`
- `../docs/STORAGE_AND_SYNC_POLICY.md`
- `../manifests/cross-surface/current.json`

```text
RESEARCH_BODY != SCIENTIFIC_ADOPTION
GITHUB_COMMIT != BW_EVENT
```
